# 我們這一屆，1980｜黑白漫畫篇

日本漫畫風的獨立新版，以全新生成的墨線、網點與四格分鏡，呈現一名 1980 年出生的台灣男孩的世代記憶。

- 八頁、三十二格，全新墨線網點畫面（黑白為主、局部少量點色），不是彩色原圖的去色版本。
- 繁體中文旁白保留為 HTML 文字，手機上清楚可讀，也方便輔助工具讀取。
- 閱讀順序：左上、右上、左下、右下。採左到右，與圖下旁白編號一致。
- 原圖轉為 WebP，含 640px 手機版本；後七頁延後載入。
- 支援目錄、上一章／下一章、鍵盤焦點、閱讀進度與列印。
- 無追蹤器、廣告、外部字型或分析工具。

## 創作說明與限制

依使用者提供文章改編。阿陳為虛構世代合成人物，不是任何人的個人傳記；不同人的經驗並不相同。畫面由 AI 生成，年代、器物與場景為藝術化重現，不是歷史照片或考證。九二一、SARS、金融危機及疫情是時代背景，個人情節均為虛構。角色與物件的細節可能隨頁面略有差異；局部可能保留少量色彩點綴。

本版是日本漫畫的視覺語彙，不代表場景位於日本。故事場景仍是台灣。
